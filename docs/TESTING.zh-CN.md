## 自动化检查

使用 Java 25 运行 Gradle，并安装 Java 17 和 Java 21 工具链，执行 `./gradlew clean build` 构建和测试全部 24 个目标。JUnit Jupiter 覆盖容量与顺序、配置恢复、权限、本地化、JSON/备份恢复、世界隔离、异步清空与保存竞争、最终刷新、文本过滤及接收者聊天可见性。快照和缓存测试覆盖变化/不变 tick、缩容、清空脏记录、停服末尾记录和惰性解码。

0.3.0 覆盖格式 3 往返、已知格式 2 升级及未知格式保护、服务端捕获时间、过滤后富文本、客户端配置校验、筛选后限额、关闭接收、协商超时/版本不符、缺失通道回退和强制系统模式保留偏好。协议测试使用真实 Minecraft 组件编解码器和自定义历史协议，不经过玩家聊天签名验证。

跨版本转换回归使用目标原生解析器校验 URL、页码及命令字符约束；不支持的点击交互局部移除并报告损失，正文及过滤分支保留，迁移后仍可落盘。连接状态回归覆盖玩家实例替换后保留 Play 会话和关闭接收偏好、1.20／1.20.1 语言保留，以及连接隔离、断线和按逻辑服清理；实际重生事件顺序仍须联机验收。

回放失败回归覆盖正常／超限／正常三条序列、过滤正文失败不得回退原文、原生占位解析及客户端本地解析失败。批次检查覆盖接收不齐、结束条数不符、占位与解析失败计数、一次汇总、重复／迟到拒绝及切服清理。正常账号限制和屏蔽不算失败；占位不绕过这些限制，不向时间／头像适配提供玩家身份。将正常、占位、损坏和已简化正文与客户端接收限制交叉验证：拒收项计入已收到，不解析、不提示，后续允许项仍显示；允许项的真实解析／显示失败仍须报告。网络发送故障仍应中止，不能当作单条内容失败吞掉。

客户端兼容性契约测试检查 Chat Patches 所需方法/字段形状及排队元数据保留条件，不运行 Chat Patches 渲染，也不在游戏内应用 Mixin。模拟服务端/玩家不创建运行中的世界或网络连接；这些测试不能证明真实事件顺序、界面行为、断线清理、Fabric 注入或实际兼容性。

客户端命令回归使用生产注册回调生成的实际 Brigadier 命令树，只解析而不执行配置写入或界面动作。普通空格为可执行正对照，Unicode 空白不能成为文字命令名称边界；各旧版适配检查按原版过滤后能够解析的配置点击均被保护拦截。26.2／26.3 使用同一实际命令树验证 `attended=false` 拒绝、`attended=true` 允许设置入口、状态、重载及配置命令。

客户端显示回归使用真实 ChatAbilities（26.1～26.3）或 ChatStatus（1.20／1.21 系列）限制及 GameNarrator 路由，以模拟语音后端替代发声，不调用游戏/语音构造器；覆盖默认跳过、配置重载、适配作用域恢复顺序及拒绝/显示失败后不播报、不重复。

公共适配边界测试覆盖筛选后限额、重复入场合并、失效玩家、回放失败后的边界关闭和记录恢复、关闭接收、最终落盘及缓存释放。两种运行时 Gson 均保留严格解析回归；正式 JAR 须检查公共类仅打包一次，并且不包含另一版本实现。

## 分版本检查

公共业务回归在 `common` 使用 Java 17 独立运行；全部 24 个游戏模块运行各自及显式共享的游戏集成回归，并补充旧 Gson 严格解析、intermediary 字节码契约、客户端命令点击限制、原版账号限制和系统旁白检查。配置任务测试覆盖未启动时等待、所属服务端收到回复／超时后只完成一次，以及断线和停服取消。26.1～26.3 使用 Java 25，1.20～1.20.4 使用 Java 17，其余目标使用 Java 21。可用 `-PgameTargets=1.20.4,1.21.11` 限定配置和构建范围。

**正式 JAR** 检查按 [版本与联动矩阵](COMPATIBILITY.zh-CN.md) 选择官方发布包。支持 Chat Patches 的目标覆盖 12 组：无联动、三种单装、三种两两组合、三者同装、时间关闭、头像关闭、错误配置、服务端环境。其余目标覆盖 8 组：无联动、Tools、头像、Tools＋头像、两个独立开关、错误配置、服务端；不包含用户暂缓的 Chat Patches 组合。检查真实 Mixin 应用、历史时间变换、发送者元数据及实时消息隔离，仅初始化注册表和测试替身，不打开窗口、不启动世界、游戏连接或模组初始化入口。

以下人工矩阵须分别在**全部目标版本**执行，依赖按 README 对应版本安装。各 1.20／1.21 及 26.1 系列目标另验收聊天 `RUN_COMMAND` 点击不能改变本地设置，而手动输入及明确提交的命令建议正常。按该版本原版规则检查本地世界聊天限制；关闭历史跳过时按对应原版旁白语义朗读：旧接口检查系统类别，1.21.6 起的系统队列接口按原版总开关处理。历史迁移与代理切服按下方第三阶段清单检查，实际联机尚未验证。

## 人工验收——须另获确认

各版另须验证入服协商等待期间重生，以及正常死亡重生／从末地返回：关闭接收偏好不丢失，1.20.1 中文命令回复不因旧玩家实例回收而退回英文。

使用可丢弃的安装目录和测试世界，记录确切模组/客户端/服务端版本、设置及结果，必要时截图。构建或自动测试通过不代表下表已经验收；自动检查不使用真实存档，不接受 EULA。

| 场景 | 预期 |
| --- | --- |
| Fabric 独立服，同版本原版客户端（每个支持版本） | 无需客户端模组即可连接；系统消息回放正确，之后实时聊天正常；Play 阶段最多约两秒等待，不阻塞入场。 |
| 双方安装；客户端没有 Chat Patches、Chat Tools、Mod Menu | 历史、命令、设置、状态独立可用；没有独立时间前缀。 |
| 正版模式安全配置开/关、离线模式 | 无需更改策略或发送临时身份/会话即可回放。 |
| `auto` 与 `system` | 前者对兼容连接增强；后者使用系统消息，同时保留协商成功的个人偏好。 |
| 个人条数及四类事件开关，混合历史 | 先筛选再取最近 N 条，按时间顺序发送；不扩大服务端范围，不改实时聊天。 |
| 关闭接收、空历史、服务端配置错误 | 协商成功关闭后，无历史及常规提示，包括配置错误提示。 |
| 配置阶段超时、协议不兼容、游戏通道缺失 | 正常入服，默认历史并提示；当前状态准确，迟到回复不改变结果。 |
| 断线重连、切换服务器 | 清除协商状态及单次警告状态，保留全局偏好。 |
| 客户端界面、命令、可选 Mod Menu | 无需服务端权限即可保存/重载；区分保存值与连接生效值；普通偏好下次连接生效。 |
| 对应版本的 Chat Patches 8.0.0，增强路径 | 玩家聊天和全部事件的时间栏、悬浮/上下文使用服务端捕获时间；时区遵从 Chat Patches。 |
| Chat Patches 时间/系统时间开关、名称及重复合并 | 用户设置优先，事件遵守系统时间开关，名称/合并/日志仍正常。 |
| 回放时 Chat Patches 正在加载旧日志 | 排队消息出队仍保留历史元数据；随后实时消息使用正常当前时间。 |
| 关闭消息时间显示兼容并重启 | 本模组的 Chat Patches、Chat Tools 时间 Mixin 不应用、不提供历史时间元数据；基础功能正常，Chat Patches 自身行为保留。 |
| Chat Patches 接口不兼容、适配运行异常 | 基础历史继续，提示一次并显示原因，不重复整批回放，不将旧元数据遗留给实时消息。 |
| 修改消息时间显示兼容开关但未重启 | 状态区分保存值和启动值，明确提示重启。 |
| 单人、无作弊 LAN 房主、原版/增强 LAN 访客 | 房主可管理，普通访客不可；接收者偏好和历史隔离。 |
| 切换两个世界 | 历史独立，安装配置共用，无失效缓存串入。 |
| 私聊/队伍聊天、队伍死亡、被拦截广播 | 不进入公共历史，公开事件仍遵守 gamerule。 |
| 文本过滤、自身消息例外、隐藏/仅系统聊天、屏蔽发送者 | 不泄露过滤正文，可见性及客户端社交限制保留。 |
| 事件开关、缩容、无效配置/重载、清空及重启 | 生效配置、淘汰、恢复及提示符合 README；清空前内容不复活。 |
| 带在线玩家停服 | 保存最终启用的退出事件。 |
| 长换行文本、大批历史 | 遵守原版/Chat Patches 窗口限制，不承诺分页或跨 tick 回放。 |
| 账号/启动器禁用玩家聊天，但允许系统消息 | 增强玩家历史不显示、不进入时间适配或旁白；系统事件正常。 |

| 保存/重载跳过设置，已有语音排队 | 后续增强正文采用新值；不清空旧队列、不补读既有消息；系统回退不受影响。 |

性能决策需区分筛选、解码、数据包编码、真实网络排队及客户端渲染。后台模拟压测仅覆盖明确计时的阶段，不能当作生产 TPS 或端到端延迟。

配置与适配管理器回归覆盖消息时间显示兼容开关、保存与重载，以及多个模拟适配器的嵌套作用域、故障通知和连接重置。正式时间适配器包含 Chat Patches 与 Chat Tools；这些单元测试不证明不同第三方 mod 同时安装的游戏内兼容性。

## Chat Heads 验收

适配自动测试覆盖准确 UUID 查询、玩家资料缺失时委托原有识别、事件隔离、元数据恢复、相同文本的队列身份区分、连接清理、独立开关及插入开始后不重试。无窗口检查验证实际可选 Mixin 变换，不验证渲染或联机兼容性。

| 场景 | 预期 |
| --- | --- |
| 仅 Chat Heads 1.3.2（26.3）／0.15.7（1.21.1）；发送者在线 | 增强玩家历史按 Chat Heads 设置显示发送者头像。 |
| Chat Heads 与 Chat Patches 8.0.0 同装 | 头像和历史时间同时正常，名称格式和重复合并不造成重复头像。 |
| 名称前／行前头像、换行、刷新 | 头像位置及发送者关联在换行和 HUD 重建后仍正确。 |
| Chat Patches 正在加载旧日志；两人文本相同 | 排队历史保留各自的头像与时间，后续实时消息及事件不串用旧头像。 |
| 发送者离线或当前玩家资料中不存在 | 沿用 Chat Heads 自己的识别；本次不要求完整离线头像，不新增资料查询或缓存。 |
| 时间关头像开／头像关时间开 | 各自独立生效；关闭头像并重启后不加载本模组的头像队列钩子。 |
| 账号限制、屏蔽、旁白跳过 | 被拒绝的聊天不进入头像适配；旁白沿用原始正文和现有设置。 |
| 接口不兼容、连接重置、10000 条历史 | 基础历史继续、不重复插入、连接元数据清理；不逐条查询离线资料。 |

## Chat Tools 验收

自动回归覆盖全部记录类型的时间作用域、时区及夏令时、异常恢复、相同文本独立排队、连接清理和上游字节码形状。正式 Chat Tools 2.4.5 JAR 的无窗口检查已核对实际前缀、悬浮与复制时间元数据，并通过单装、与 Chat Patches/Chat Heads 同装、开关关闭、错误配置、缺失模组及服务端类加载检查。没有启动游戏或调用模组初始化入口；以下项目仍待实机验证。

| 场景 | 预期结果 |
| --- | --- |
| Chat Tools 2.4.5，玩家聊天及全部事件 | 前缀、悬浮日期/时区、复制时间使用服务端捕获时间；随后实时聊天时间正常。 |
| 时间功能关闭、自定义格式、跨夏令时日期 | 尊重 Chat Tools 设置及历史时刻的本地时区偏移；不强加前缀。 |
| 与对应的 Chat Patches 8.0.0、Chat Heads 1.3.2／0.15.7 同装 | 历史时间及现有头像能力正常；可在上游设置关闭多余时间前缀。 |
| Chat Patches 加载旧日志时入服；头像兼容关闭 | 出队仍保留各条历史时间；同文本记录不串时间；断线后不残留。 |
| 时间兼容关闭并重启、模组缺失或接口不支持 | 对应时间钩子不应用，基础历史可用，状态原因明确；头像开关独立。 |
| Chat Tools 重复合并、复制菜单、历史刷新 | 按上游规则显示/复制，不重复添加时间前缀；核对合并后的时间语义及元数据。 |
| 强制系统回退 | 不承诺历史时间；Chat Tools 可显示本次接收时间。 |

## 第三阶段验收

自动测试包括各目标实际正文解析器、全部迁移方向、过滤正文隔离、损失统计、固定单份迁移备份、未知编码阻止覆盖、原生路径不转换、惰性缓存共享与淘汰，以及会话标识、重复／迟到消息、边界、UTF-8／长度限制、超时和等待期间不重复实时聊天。1.20.1 使用 Java 17，检查旧通道、客户端语言捕获和 Chat Patches 五参数队列；各版均检查后端登录重置钩子的实际注入。

正式 JAR 矩阵使用上方各目标的 8／12 组范围。无窗口检查不代表真实渲染、聊天恢复时序或代理透传已经验收。开发资源检查应使用真实 Loader 发现器，确认公共语言 JAR 也在 Loom 模组分组内；发布包须核对同名类无重复、语言完整及元数据匹配当前游戏。

另获许可后人工检查：各版原版客户端；不同适配边界的客户端与服务端代理交叉矩阵；后端 A → B → 无模组服 → A；协商期间切服、断线和迟到数据；同一维度切服；客户端配置关闭；通道被代理拦截时一次系统回退。迁移测试必须使用可丢弃文件，核对 `.previous-version` 原件、`.bak` 新格式、损失状态、失败后禁止写入和明确清空后的恢复。不要将可打开聊天文件等同于 Minecraft 世界存档可降级。
